# วิธีประกอบเคสจอราคาทอง (v2)

ไม่ต้องใช้น็อตหรือเครื่องมือ — ใช้มือเปล่า

## ก่อนประกอบ

1. แกะ brim รอบขอบหน้ากล่องออก แล้วลบคมด้วยกระดาษทรายเบอร์ 240
2. ลองเสียบสาย USB-C ที่รูด้านขวาของกล่องเปล่า ๆ — ปลายโลหะต้องโผล่เข้าไปในกล่องได้ ~2 มม.

## ประกอบ

1. **ESP32 ลงฝา:** วางบอร์ดคว่ำ (ด้านชิปลงหาฝา) ลงช่องระหว่างผนังกั้น ให้หัว USB หันไปทางปลายฝาที่มีผนังกั้นชิดขอบ (ปลายเดียวกับรู USB ของกล่องเมื่อปิดฝา)
2. **เสียบสาย:** เสียบสาย Jumper 5 เส้นที่ ESP32 และขั้ว IN ของจอ
3. **ใส่จอ:** หันหน้า LED ลง ใส่เข้ากล่องทางด้านหลัง ดันจนชนขอบหน้า — ขั้ว IN อยู่ด้านขวาเมื่อมองจากหน้า
4. **พับสาย:** พับสายเข้าช่องว่างระหว่างหลังจอกับ ESP32
5. **ปิดฝา:** กดฝาให้ตรง ไล่กดจากซ้ายไปขวาจนได้ยินคลิกครบ — เดือยบนฝาจะดันจอให้ชิดหน้า และสันในกล่องจะกด ESP32 ให้แน่น

**เปิดฝา:** สอดไขควงปากแบนที่ร่องเล็กใต้เครื่อง (ขอบล่างตรงรอยต่อฝา ค่อนมาทางซ้ายเมื่อมองจากหน้า) งัดเบา ๆ แล้วดึงฝาออกตรง ๆ

**ปุ่ม BOOT:** กดที่แผ่นเล็กใต้ตัวหนังสือ "BOOT" บนฝาหลัง

## ถ้าไม่พอดี

| อาการ | แก้ |
|---|---|
| ESP32 ลงช่องไม่ได้ | ขัดผิวด้านในของผนังกั้นปลายบอร์ด |
| ESP32 คลอน | พันสก๊อตเทป 1–2 รอบที่ผนังกั้น |
| จอใส่ไม่ลง | ขัดผนังด้านในบน/ล่างของกล่อง |
| ฝาปิดยากมาก | ขัดร่องรับตัวล็อกในผนังกล่อง (ไม่ใช่ตัวล็อกบนฝา) |
| ฝาคลอน | แปะเทปโฟมบาง ๆ ที่ขอบฝาด้านใน |
| หัว USB เข้าไม่สุด | หัวสายใหญ่กว่าหลุมรอบรู (13 × 7 มม.) → ขัดขอบหลุมให้กว้างขึ้น หรือใช้สายหัวเล็ก |
| ESP32 ไม่บูต / ค้างตอนเปิด | ปุ่ม BOOT ถูกกดค้าง → ขัดปลายแกนกดบนฝาให้สั้นลงทีละน้อย |
| กดปุ่ม BOOT ไม่ติด | แปะเทป 1–2 ชั้นที่ปลายแกนกด |

## ห้ามขัด

- **ขาเกี่ยวตัวล็อกบนฝา** (10 ตัว) — บาง 1.2 มม. ขัดแล้วหัก/ไม่ล็อก
- **แผ่นสปริงบนฝา** (6 แผ่น ที่มีร่องรูปตัว U รอบ) — ขัดแล้วหมดแรงดันจอ
- **แผ่นปุ่ม BOOT** — ขัดได้เฉพาะปลายแกนกด
- **ขอบหน้าต่างจอด้านหน้า** — ขัดแล้วเห็นรอย
