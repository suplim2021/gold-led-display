# ใบสั่งพิมพ์ — เคสจอราคาทอง (v2)

ไฟล์ STL **วางทิศพร้อมพิมพ์แล้ว** — ลากเข้า Bambu Studio ได้เลย ไม่ต้องหมุน ไม่ต้องใส่ support

## ไฟล์ที่ต้องพิมพ์ (2 ชิ้น)

| ไฟล์ | ขนาดบนฐาน (มม.) | ด้านที่วางฐาน |
|---|---|---|
| `stl/v2/CASE_Body.stl` | 163.8 × 50.5 สูง 50.6 | **หน้ากล่อง (ด้านจอ)** |
| `stl/v2/CASE_BackCover.stl` | 163.8 × 37.8 สูง 40.2 | **ผิวนอกฝา** |

พอดีกับ Bambu Lab A1 mini (180 มม.) และ A1

## ค่าที่ใช้

| ค่า | ตั้ง |
|---|---|
| วัสดุ | **PETG สีดำ** (ไม่ใช้ PETG-CF) |
| หัวพิมพ์ | 0.4 มม. |
| ความสูงชั้น | 0.2 มม. |
| Wall loops | 3 |
| Top/bottom | 4 ชั้น |
| Infill | 15–20% gyroid |
| Support | **ไม่ใช้** |
| ฐาน | Textured PEI (หน้ากล่องจะได้ผิวด้านเนียน) |
| Brim | **ตัวกล่อง: brim 3 มม.** (ขอบเหลือน้อยบน A1 mini) / ฝา: ไม่ต้อง |
| Bridge | ใช้ค่าในโปรไฟล์ PETG ได้ (สะพานยาวสุด 13 มม. ที่หลุม USB ตื้น 1 มม.) |
| Scale | 100% — ห้ามย่อ/ขยาย |

## จุดที่ต้องระวัง

- ห้ามหมุนชิ้นงาน — ทิศนี้ทำให้ตัวล็อกและสปริงแข็งแรงที่สุด
- ห้ามเปิด XY hole/contour compensation (ระยะเผื่อประกอบคิดไว้ในไฟล์แล้ว)
- ฝามีตัวล็อก 10 จุด แผ่นสปริง 6 แผ่น และปุ่มกด 1 จุด หนา 1.2–1.4 มม.
- ผิวนอกฝามีตัวหนังสือ "BOOT" แกะลึก 0.4 มม. — อยู่ด้านที่วางบนฐาน พิมพ์ได้ตามปกติ
- ปริมาณเนื้อพลาสติกรวม ~86 ซม³ (กล่อง ~67, ฝา ~19)
