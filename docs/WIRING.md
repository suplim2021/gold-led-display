# ผังการต่อสาย ESP32 ↔ MAX7219 4-in-1 (32×8)

> ⚠️ **ยังไม่ได้ทดสอบกับฮาร์ดแวร์จริง** — ผังนี้เตรียมจาก datasheet และ pinout มาตรฐาน
> ต้องตรวจป้ายขาบนบอร์ดจริงก่อนจ่ายไฟทุกครั้ง

## สรุป: แบบไหนผ่านข้อกำหนดทางไฟฟ้า

| แบบ | ชิ้นส่วนเพิ่ม | Logic level ตามสเปก MAX7219 | ใช้เมื่อ |
|---|---|---|---|
| **A. Prototype 5 เส้น** | ไม่มี | ❌ **ไม่ผ่าน** (3.3V < VIH ขั้นต่ำ 3.5V) — มักใช้งานได้จริง แต่ไม่รับประกัน | ทดลองเร็ว ๆ |
| **B. ผ่าน SN74HCT125N / SN74AHCT125N** | ชิป 1 ตัว + C 0.1µF | ✅ **ผ่าน** (HCT รับ 3.3V ได้ เพราะ VIH = 2.0V และส่งออก 5V) | ใช้งานถาวร / ถ้าแบบ A มีอาการเพี้ยน |

ที่มา: MAX7219 datasheet — VIH (DIN, CLK, LOAD) ขั้นต่ำ 3.5V เมื่อ V+ = 5V; ESP32 GPIO ส่ง High ≈ 3.3V

## แบบ A — Prototype 5 เส้น (ต่อตรง)

ต่อที่ฝั่ง **IN** ของโมดูล (ฝั่งที่มีขา DIN, ไม่ใช่ DOUT)

| MAX7219 (IN) | ESP32 DevKit 30 pin | หมายเหตุ |
|---|---|---|
| VCC | **5V / VIN** | บนบอร์ด 30 ขาหลายรุ่นพิมพ์ว่า `VIN` = ไฟ 5V จาก USB (ผ่านไดโอด) |
| GND | GND | |
| DIN | GPIO23 (`D23`) | VSPI MOSI (hardware SPI) |
| CLK | GPIO18 (`D18`) | VSPI SCK (hardware SPI) |
| CS / LOAD | GPIO5 (`D5`) | เปลี่ยนได้ที่ `DISPLAY_CS_PIN` |

```
 ESP32 DevKit                    MAX7219 4-in-1 (ฝั่ง IN)
 ┌──────────┐                   ┌─────────────────────┐
 │  VIN(5V) ├───────────────────┤ VCC                 │
 │      GND ├───────────────────┤ GND                 │
 │      D23 ├───────────────────┤ DIN                 │
 │       D5 ├───────────────────┤ CS                  │
 │      D18 ├───────────────────┤ CLK                 │
 └──────────┘                   └─────────────────────┘
```

**อาการที่บอกว่าแบบ A ไม่เสถียร:** จอแสดงจุดสุ่ม, บางโมดูลไม่ติด, ภาพเพี้ยนเมื่อสายยาว/ไฟตก → เปลี่ยนเป็นแบบ B

## แบบ B — ผ่าน SN74HCT125N (แนะนำสำหรับใช้งานจริง)

Pinout SN74HCT125N / SN74AHCT125N (DIP-14, มองจากด้านบน รอยบากอยู่ซ้าย):

```
        ┌───U───┐
 1OE  1 │       │ 14 VCC (5V)
  1A  2 │       │ 13 4OE
  1Y  3 │       │ 12 4A
 2OE  4 │       │ 11 4Y
  2A  5 │       │ 10 3OE
  2Y  6 │       │  9 3A
 GND  7 │       │  8 3Y
        └───────┘
```

| ขาชิป | ต่อกับ | หน้าที่ |
|---|---|---|
| 14 VCC | 5V (VIN) | ไฟเลี้ยงชิป 5V |
| 7 GND | GND | |
| 1, 4, 10 (1OE, 2OE, 3OE) | GND | เปิดใช้ช่อง 1–3 (active LOW) |
| 2 (1A) | ESP32 GPIO23 | |
| 3 (1Y) | MAX7219 DIN | |
| 5 (2A) | ESP32 GPIO18 | |
| 6 (2Y) | MAX7219 CLK | |
| 9 (3A) | ESP32 GPIO5 | |
| 8 (3Y) | MAX7219 CS | |
| 13 (4OE) | 5V | ปิดช่อง 4 ที่ไม่ใช้ |
| 12 (4A) | GND | ไม่ปล่อยขา input ลอย |
| 11 (4Y) | ไม่ต่อ | |
| C 0.1µF (104) | คร่อมขา 14–7 ให้ใกล้ชิปที่สุด | bypass capacitor |

ไฟ VCC/GND ของ MAX7219 ต่อ 5V/GND เหมือนแบบ A, **GND ทุกจุดต้องต่อร่วมกัน**

```
 ESP32            74HCT125              MAX7219 (IN)
 D23 ──────────── 2 (1A)  3 (1Y) ────── DIN
 D18 ──────────── 5 (2A)  6 (2Y) ────── CLK
 D5  ──────────── 9 (3A)  8 (3Y) ────── CS
 VIN(5V) ──┬───── 14 VCC ─┬──────────── VCC
           │       13 4OE─┘
           │     [0.1µF] 14↔7
 GND ──────┴───── 7 GND, 1, 4, 10, 12 ── GND
```

## ไฟเลี้ยง — ต้องตรวจ

- ห้ามสมมติว่า **หัวชาร์จ 2A = ขา 5V/VIN ของ ESP32 จ่ายได้ 2A** — กระแสผ่านไดโอด/ฟิวส์/ลายวงจรบนบอร์ด ESP32 ซึ่งพิกัดมักต่ำกว่า (ตรวจจากบอร์ดจริงหรือ schematic ของรุ่นที่ซื้อ)
- MAX7219 4 โมดูลตอนเปิดทุกดวงที่ความสว่างสูงสุดอาจกินกระแสหลายร้อย mA ถึงเกิน 1A; ตัวเลขที่ความสว่าง `1` ใช้กระแสน้อยกว่ามาก (ยังไม่ได้วัดจริง)
- เริ่มที่ `DISPLAY_INTENSITY 1`, วัดแรงดันที่ขา VCC ของจอ (ควร ≥ 4.75V), สังเกตความร้อนของไดโอด/บอร์ด และการรีสตาร์ท (ดู Serial log `[boot]` ซ้ำ ๆ)
- ถ้าไฟไม่พอ: ใช้ 5V จากแหล่งจ่ายแยก ป้อนเข้าจอโดยตรง และ **ต่อ GND ร่วมกับ ESP32**
- อย่าเสียบ USB ของ ESP32 พร้อมกับป้อน 5V ภายนอกเข้าขา VIN โดยไม่มีวงจรป้องกันไฟย้อน

## หมายเหตุขา GPIO

- GPIO23/18 คือ hardware SPI (VSPI) — ถ้าเปลี่ยนขาต้องแก้โค้ดให้ใช้ software SPI
- GPIO5 เป็น strapping pin (ต้องเป็น High ตอนบูต) — CS ของ MAX7219 idle เป็น High อยู่แล้วจึงใช้ได้ ถ้าบูต/อัปโหลดมีปัญหา ให้ย้าย CS ไป GPIO16, GPIO17 หรือ GPIO21 (ไม่ใช่ strapping pin) แล้วแก้ `DISPLAY_CS_PIN`
- ปุ่ม **BOOT (GPIO0)** บนบอร์ดกดสั้น = เปลี่ยนโหมดแสดงผล, กดค้าง 5 วินาที = ตั้ง Wi-Fi ใหม่

## Checklist ก่อนจ่ายไฟครั้งแรก

1. ตรวจป้ายขาบนบอร์ด ESP32 จริง (5V/VIN, GND, D23, D18, D5)
2. ตรวจว่าต่อฝั่ง **IN** ของจอ (ลูกศรบน PCB ชี้ออกจาก IN)
3. ใช้มัลติมิเตอร์โหมด continuity เช็ค VCC–GND ต้อง **ไม่ลัดวงจร**
4. เช็คขั้ว VCC/GND ไม่สลับ
5. จ่ายไฟจาก USB ของ PC ก่อน (มี current limit) แล้วดู Serial Monitor
